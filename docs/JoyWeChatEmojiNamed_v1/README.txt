Joy 微信 109 小表情 - Agent 版

文件命名规则：
[666]   -> 666.png
[奸笑]  -> 奸笑.png
[旺柴]  -> 旺柴.png
[微笑]  -> 微笑.png
……

特点：
- 使用你提供的两张微信表情面板截图直接裁剪，没有 AI 重绘。
- 使用透明背景 PNG，方便 Agent 作为本地资源。
- 109 个文件与截图中的顺序一一对应。
- emoji_map.json / emoji_map.csv / emoji_map.js 可以直接作为 Agent 的标签映射表。
- 文件名不含 []，即程序收到 [xxx] 后可直接取 xxx.png。
