# Joy 隐私说明

最后更新：2026-09-23

## 我们收集什么？

**Joy 项目方不收集任何数据。** 没有账号体系，没有自建上报服务器。

本程序在你本机运行。网络请求只发往**你在设置里配置的模型服务商**（例如商汤 SenseNova、Moonshot、阿里云 DashScope、智谱、硅基流动、DeepSeek、OpenAI 或你自填的 Base URL）。

## 读了什么

- 你指定或自动附着的窗口客户区截图（默认仅内存中的图像数组，不写磁盘）。
- 可选：会话名、关系与说话风格等你自己填写的文本配置（存在本机 `config.json`，不含密钥）。

## 什么时候出网、发出去什么

仅在你触发「分析」或检测到对方新消息需要分析时：

1. **视觉 / 识图**：裁剪后的截图（通常为 JPEG Base64）+ 识图提示词 → 你配置的视觉 API。
2. **判断 / 起草**：结构化后的最近 N 条对话文本、关系与风格等 → 你配置的文本 API。

启动时若开启「检查更新」，可能向 GitHub Releases 发一次版本查询（不含聊天内容）；可在设置中关闭。

## 密钥存在哪里

API Key 写入本机环境变量或系统凭据（实现以代码为准），**不进** `config.json`、不进 git、不进常规日志。报错文本会脱敏。

清除方式：在设置页清空各卡密钥，或删除对应环境变量 / 凭据项。

## 截图会落盘吗？

默认不会。仅开发用的 `scripts/` 探测工具在显式开启时可能存图；正式发布路径默认关闭。
